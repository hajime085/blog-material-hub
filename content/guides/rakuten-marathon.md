お買い物マラソンで、いちばん多い失敗はこれだと思います。**あと1店舗で倍率が上がるから、と1,000円のものを足す。**気持ちはよく分かります。ただ、その1,000円で増えるポイントは、多くの場合1,000円もありません。

この記事は、**楽天スーパーSALEとは別のイベント**であるお買い物マラソンについて、数え方のルールと、どこで損が生まれるのかを、読む順番どおりに並べ直したものです。

# 結論｜マラソンは「ポイントを積む」イベント

先に結論を置きます。

> マラソンは「安く買う」イベントではなく、「ポイントを積む」イベントです

- 買い方は、**エントリー → 買うものを書き出す → ショップごとに分ける → 1,000円に届かない店を確認する → 「あと1店舗」を計算する → 5と0のつく日と重ねる → 送料と条件を確かめて買う**、の順です。
- **10店舗を目指さない。**必要なものを必要な数だけ買った結果の店舗数が、正解です。
- **「あと1店舗」は計算してから決める。**目安は「いまの合計が、足す商品の90倍を超えているか」です（理由は注意の節で計算します）。

そしてもうひとつ。お買い物マラソンは**ほぼ毎月あります。**今回逃しても、来月また来ます。この一点を頭に入れておくだけで、無駄な駆け込みがかなり減ります。

## スーパーSALEとの違い

名前が似ていて、買いまわりの仕組みも同じなので混同されがちですが、**中身はかなり違います。**

| | お買い物マラソン | 楽天スーパーSALE |
|---|---|---|
| 主役 | **ポイント** | **値引き** |
| 半額商品 | ほとんど出ない | 目玉として出る |
| 開催 | ほぼ毎月 | 年に4回ほど |
| 焦り度 | 低い（また来る） | 高い（次は3ヶ月後） |

スーパーSALEと同じ気持ちで半額商品を探しにいくと、見つからずに肩透かしを食らいます。逆に、買うものがもう決まっているなら、マラソンのほうが使いやすいイベントです。

# 参加条件｜買いまわりの仕組みと数え方

買いまわりのルール自体は単純です。

- 期間中に、**1つのショップで税込1,000円以上**買うと、1店舗としてカウントされる
- カウントが増えるほど、**ポイントの倍率が上がる**
- **最大10ショップ**まで。10店舗で+9倍（通常の1倍と合わせて10倍）

「10ショップで10倍」と聞くと大きく感じますが、増えるのは**+9倍ぶん**です。ここは後で効いてきます。

## エントリーを忘れると、ゼロです

買いまわりは**エントリーした人だけ**が対象です。エントリー前に買った分は、期間中でもカウントされません。買い物を始める前に、まずエントリーを済ませてください。

# 買いまわりの進め方｜そのまま使える手順

## STEP1｜エントリーする

何よりも先です。これを忘れると全部ゼロになります。

## STEP2｜買うものを書き出す

**買う前に**書き出してください。買いながら探すと、必ず要らないものが混ざります。書き出すときは、3つに分けると判断が楽になります。

- **絶対に買うもの** — 切らしている日用品、決めていた買い替え
- **安ければ買うもの** — 値段しだいで決めるもの
- **今回は要らないもの** — 気になっているだけのもの

3つ目は、この時点で外してください。

## STEP3｜ショップごとに分ける

1つ目と2つ目のリストを、ショップごとにまとめます。ここで**何店舗になるか**が見えます。同じショップにまとまるものは、まとめて買ってください。カウントは1のままですが、送料が1回で済みます。

## STEP4｜1,000円に届かない店を確認する

商品代（税込）が1,000円未満の店があれば、その店はカウントされません。

- その店で**もともと必要なもの**を足せるなら、足す
- 足せないなら、**その1店舗は諦める**

ここで要らないものを足さないことが、いちばん効きます。

## STEP5｜「あと1店舗」を計算する

下の「注意」の節にある「増える倍率 × 合計金額」で、割に合うかを確かめてください。計算なしに足さないのが、この記事の結論です。

## STEP6｜5と0のつく日と重ねる

マラソン期間中に5と0のつく日が入っていれば、その日に買うと倍率がさらに上がります（エントリーと楽天カードの利用が条件です）。サイドバーのカレンダーで、その日がいつかを見られます。

商品代と送料の**合計**で見てください。北海道・沖縄・離島にお住まいなら、送料欄を必ず開いてください。

# 注意点｜損が生まれる5つの条件と、上限の落とし穴

ここが実際に損が出るところです。先に一覧で押さえてから、それぞれを読みます。

| 条件 | 内容 |
|---|---|
| 1｜送料 | 送料は1,000円の判定に入らない。商品代金（税込）で判定する |
| 2｜同じショップ | 同じショップで2回買ってもカウントは1店舗 |
| 3｜キャンセル・返品 | キャンセル・返品した分はカウントが無効になる |
| 4｜買う順番 | 順番は関係ない。最終的な店舗数が期間中の買い物に適用される |
| 5｜対象外 | 対象外の商品・ショップがある。条件が別のサービスもある |

## 1｜送料は1,000円の判定に入りません

**商品代金（税込）が1,000円以上**である必要があります。

- 商品900円 ＋ 送料300円 ＝ 支払い1,200円 → **カウントされません**
- 商品1,000円 ＋ 送料300円 ＝ 支払い1,300円 → カウントされます

「合計で1,200円払ったのに数えられていない」という食い違いは、だいたいこれです。

## 2｜同じショップで2回買っても、1店舗です

期間中に同じショップで3回買っても、カウントは**1**です。店舗数を増やしたいなら、別のショップで買う必要があります。逆に言えば、**同じショップでまとめ買いしても損はしません。**カウントは変わらないので、送料を1回で済ませたほうが得なことが多いです。

## 3｜キャンセル・返品した分は無効になります

購入後にキャンセルすると、その店舗のカウントは消えます。すでに10店舗達成していたつもりでも、9店舗に戻ります。

## 4｜買う順番は関係ありません

これは誤解が多いところですが、**先に買った分も、後から買った分も、同じ倍率が適用されます。**「高いものは最後に買ったほうがいい」という話を見かけますが、買いまわりに関してはそうではありません。期間中に達成した最終的な店舗数が、期間中のすべての買い物に適用されます。ただし、**期間中に必ず達成できるとは限らない**ので、達成を前提に高額品を先に買うのは、それはそれで賭けになります。

## 5｜対象外の商品・ショップがあります

一部の商品や、楽天ブックスなど一部のサービスは、条件が別に決められていることがあります。買う前に、その回のキャンペーンページで対象を確かめてください。

## 本題｜ポイントには上限があります

買いまわりで得られるポイントには、**獲得上限**が設定されています。上限は回によって変わるため、この記事では具体的な数字を書きません。**その回のキャンペーンページに必ず書いてあります**ので、そこで確認してください。なぜこれが本題なのかというと、**上限に達した瞬間から、店舗を増やす意味がなくなるからです。**合計金額が大きい人ほど、上限に早く届きます。上限に達したあとに店舗を増やしても、ポイントは増えません。「10店舗達成」を目標にしないほうがいい理由が、ここにあります。

## 「あと1店舗」を足すべきか、の考え方

上限に達していない前提で、こう考えてください。ポイントは2か所で増えます。

> ① いま買う予定の合計 × 1%（買いまわりが+1倍になるので、**買い物全体に**乗ります）
> ② 足した商品の値段 × あなたの倍率（**その商品自身も**ポイントを稼ぎます）

たとえば、すでに合計30,000円を買う予定で、あなたの倍率が10倍だとします。ここに1,000円のものを足すと、

| | |
|---|---:|
| ① 買い物全体に+1倍 | +300ポイント |
| ② 足した商品ぶん | +100ポイント |
| 出費 | −1,000円 |
| **差し引き** | **−600円** |

**600円の損**です。要らないものを足せば、たいてい損になります。逆に、合計100,000円を買う予定なら①だけで約1,000ポイント。②と合わせれば足した金額を上回ります。**もともと必要なものなら、足す価値があります。**境目はおおよそ「**いまの合計が、足す商品の90倍を超えているか**」です。1,000円のものなら、合計9万円が目安になります。つまり、**「あと1店舗」に意味があるかどうかは、あなたの買い物の総額で決まります。**一律の正解はありません。

## 「実質◯円」に気をつける

マラソン期間中は、この表記がとても増えます。**「実質1,800円」**これはたいてい、**ポイント還元を差し引いた計算上の値段**です。レジで払う金額ではありません。3,000円の商品でポイント20倍なら、600ポイント戻って「実質2,400円」と書かれます。**ただし今日払うのは3,000円です。**そして、買いまわりで付くポイントは**期間限定ポイント**です。有効期限が短く、使い道も楽天の中に限られます。現金と同じものではありません。ポイントを勘定に入れること自体は構いません。ただ、**現金の値段と混ぜて比べないこと**です。この手の表記の見分け方は、[その「◯%OFF」は本当か](/guide/price-trick/)にまとめています。マラソン中はとくに役に立つはずです。

# 買う前のチェック

そのまま使えるように並べました。チェックした状態はこの端末に保存されます。

- [ ] **エントリーした** — 買い物の前に済ませた
- [ ] **買うものを書き出した** — 買いながら探していない
- [ ] **各ショップで商品代が税込1,000円以上か確かめた** — 送料は含まない
- [ ] **同じショップの買い物はまとめた** — カウントは1のままなので
- [ ] **「あと1店舗」を計算した** — 増える倍率 × 合計金額で判断した
- [ ] **ポイント上限を確認した** — その回のキャンペーンページで見た
- [ ] **「実質」の表記に引っかかっていない** — 払う金額で比べた
- [ ] **送料を足した合計で比べた** — 届け先の送料も見た

全部埋まったなら、たぶん損はしていません。

**いいえ。**目指すべきは店舗数ではなく、必要なものを必要な数だけ買うことです。

3店舗でも5店舗でも、要らないものを買っていなければ、それが正解です。

焦って要らないものを買うくらいなら、来月にしてください。
</details>

<details class="qa">
<summary>スーパーSALEとどちらを待つべきですか</summary>

半額のような大きな値引きは、マラソンではほとんど出ません。値段そのものを下げたいなら、スーパーSALEを待つほうが分があります。攻略の手順は[楽天スーパーSALEの攻略法](/guide/rakuten-super-sale/)にまとめています。
</details>

<details class="qa">

</details>

<details class="qa">

</details>

<details class="qa">
<summary>ポイント上限に達したら、どうなりますか</summary>
**そこで止まります。**上限に達したあとに店舗を増やしても、ポイントは増えません。合計金額が大きい人ほど上限に早く届くので、「10店舗達成」を目標にしないほうがいい理由がここにあります。上限は回によって変わるため、その回のキャンペーンページで確認してください。
