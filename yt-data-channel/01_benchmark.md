# 参考チャンネルの分解: 恋愛「数字」チャンネル（@lovebynumbers）

> 表記ルール: **【事実】** 検索で確認できたこと ／ **【未確認】** 取れなかったこと ／ **【仮説】** 推測。
> 仮説は実数で検証するまで設計の前提にしない。

## 1. 確認できたこと【事実】

検索エンジンに出ているチャンネル説明文の要旨:

- 恋愛・結婚を、経験談ではなく**確かめられるデータ**で扱う
- 出典は**国勢調査・出生動向基本調査などの公的統計**と、**査読を通った研究**
- 数字は**出所を画面に表示**し、加工したものは**その手順も示す**
- 統計で説明がつかない範囲に入ったら、そこから先は**仮説として区切る**
- **結論に都合の悪い数字も落とさない**
- 「どうすればいいか（対処法）」ではなく「**何が起きているか（構造）**」を説明する
- 日本語チャンネル。英語名は Love by Numbers

**見るべきポイント**: 「2週間で収益化」は 4,000 時間（=24万分）を2週間で稼いだことを意味する。
平均視聴時間 6 分なら約 4 万再生、10 分なら約 2.4 万再生。
**1本がバズったのか、全体が底上げされたのか**で、真似すべき点がまったく変わる。上位5本の再生数の偏りを最初に見る。

## 3. なぜ伸びたか【仮説】

### H1. 「比較欲求 × 不安」の強いテーマ
未婚化・晩婚化・「年収と結婚」は、視聴者が**自分の位置を確かめたくなる**話題。
「平均は？」「自分は少数派？」という問いは検索もおすすめも強い。

### H2. 既存の恋愛ジャンルとの差別化
恋愛系 YouTube は経験談・テクニック・恋愛相談が中心。
「**出典つきの数字しか言わない**」は、それ自体がポジショニングになっている。
信頼できるので、コメント欄での議論（反論・自分語り）が起きやすく、エンゲージメントが上がる。

### H3. 長尺で視聴時間を稼ぐ設計
収益化の条件は「長尺の総再生時間」なので、2週間での達成は**長尺動画の視聴維持**が前提。
データを1つずつ積み上げる構成は、「答えを最後まで見たい」動機を作りやすい。

### H4. 公的統計は「ネタ切れ」しない
出生動向基本調査だけでも設問が数百ある。1つの調査から何本も作れるので、
**立ち上げ直後に高頻度で投稿できる**（初速を作りやすい）。

### H5. 量産に耐える制作工程
出典を画面に出す・加工手順を示すという規則は、裏を返せば
「**データ → 図 → 台本**」が型化できるということ。パイプラインで回している可能性が高い。

## 4. 真似するもの / 真似しないもの

| 真似する（型） | 真似しない（中身） |
|---|---|
| 公的統計＋査読論文だけを出典にする | 恋愛・結婚というテーマ（直接の競合になる） |
| 出典と加工手順を画面に出す | 個別の動画タイトル・構成のコピー |
| 事実と仮説の境界を明示する | 映像素材・サムネの流用 |
| 都合の悪い数字も出す | チャンネル名の類似（混同されると不利） |
| 「対処法」ではなく「構造」を語る | |
| 1つの調査から複数本を切り出す制作方式 | |

> 型の模倣は問題ないが、**中身のコピーは「再利用コンテンツ」判定と著作権の両方で危ない**。
