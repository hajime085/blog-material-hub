# 別テーマ候補の比較

参考チャンネルの型（公的統計＋査読論文だけ／出典表示／構造を語る）を移植できるテーマを9案比べた。

## 1. 採点の軸（各1〜5点、高いほど良い）

| 軸 | 見ていること |
|---|---|
| **フック** | 「自分は平均より上か下か」「みんなはどうなの」という比較欲求・不安の強さ |
| **データ** | 日本の公的統計・査読論文の厚さ、更新頻度、e-Stat で取れるか |
| **単価** | 広告単価（RPM）。金融・不動産・転職・教育は高い |
| **競合** | 「データだけで語る」チャンネルの少なさ（ジャンル全体の混雑ではない） |
| **安全** | 収益化ポリシー上のリスクの低さ（医療誤情報、AIが金融助言する形、恐怖を煽る内容） |
| **量産** | 1つの調査から何本作れるか、ネタ切れしにくさ |

> 点数は**調査時点での判断**であって、実測ではない。特に「競合」は YouTube を直接検索できなかったため、
> 着手前に YouTube でテーマ名＋「データ」「統計」で検索して上位の顔ぶれを確かめること。

広告単価の目安（日本、2026年の各種まとめ記事より）: 全体平均 RPM 100〜200円程度、金融・投資は 800〜2,500円、
医療・美容・健康は CPM 600〜1,000円。恋愛は中〜低めとみられる。

## 3. 候補ごとのメモ

### A. お金と働き方 ― **推奨**
- **なぜ合うか**: 恋愛チャンネルの核である「自分の位置を確かめたい」が最も強いテーマ。年収・貯金・残業は誰もが比べたい
- **使えるデータ**: 賃金構造基本統計調査（厚労省・毎年）、民間給与実態統計調査（国税庁・毎年）、就業構造基本調査（総務省・5年ごと）、
  労働力調査（毎月）、家計調査（毎月）、全国家計構造調査（5年ごと）、雇用動向調査（転職入職率）、家計の金融行動に関する世論調査
- **競合**: マネー系チャンネルは非常に多いが、ほぼ全部が「どうすれば増えるか（助言）」。
  **「助言しない・構造だけ」の立ち位置は空いている**とみる（要確認）
- **リスク**: 金融は YouTube が「AI ペルソナが助言すると収益化しない」と名指ししている分野。
  → **銘柄・商品・投資判断に一切触れない**。AI の人物キャラを「専門家」として出さない。これで回避できる
- **単価**: 最上位クラス。同じ再生数でも恋愛の数倍になりうる

### B. 老後・人生後半
- 年金・介護・高齢者のひとり暮らし。視聴者層の年齢が高く、長尺を最後まで見る傾向があり、総再生時間を稼ぎやすい
- データ: 国民生活基礎調査、高齢社会白書、介護保険事業状況報告、家計調査（高齢無職世帯）、人口動態統計
- 弱点: 不安を煽る方向に寄りやすい。年金は金融助言と紙一重
- **A のサブシリーズとして持つ**のが効率的（「60代の年収と貯蓄」など）

### C. 子育てと教育費
- 「子ども1人にいくらかかるか」「塾に行く子の割合」は強い比較ネタ
- データ: 子供の学習費調査（文科省・隔年）、学校基本調査、全国学力・学習状況調査、21世紀出生児縦断調査
- 弱点: 出生動向基本調査の夫婦調査を使うと**参考チャンネルとテーマが重なる**。視聴者層が子育て世代に絞られる

### F. 住まいと街
- 家賃・持ち家率・どこから人が出ていくか。不動産広告で単価は高め
- データ: 住宅・土地統計調査（2023年実施分）、住民基本台帳人口移動報告、地価公示、国勢調査
- 弱点: 地域ネタは視聴者が分散する。地図表現の制作負荷が高い

### D. 健康と体
- 需要は大きいが、医療誤情報ポリシーと AI ペルソナ規定の両方にかかる。**新規チャンネルの最初のテーマには向かない**

### E. 孤独と人間関係
- 参考チャンネルの視聴者と重なり、もっとも「隣のジャンル」。ただしデータが薄く単価が低い

### G / I / H
- G は社会生活基本調査の最新結果が 2021年実施分で、2026年実施分の公表待ち。公表後なら強い
- H は広告主に敬遠されやすく単価が低い。恐怖を煽る構成は「不快なコンテンツ」に寄る

## 4. 推奨

**A「お金と働き方」を主テーマ、B「老後」を同じチャンネル内のシリーズに。**

理由:
1. 比較欲求（フック）が最大で、参考チャンネルの勝ち筋がそのまま使える
2. 公的統計が毎年・毎月更新されるので、**最新データが出るたびに作れる**（時事性が自動で生まれる）
3. 単価が最上位。同じ登録者数・再生数でも収益が大きい
4. 「助言しない」立ち位置は、競合との差別化とポリシー回避を**同時に**満たす
