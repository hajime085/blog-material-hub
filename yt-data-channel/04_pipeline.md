# 制作パイプラインと、収益化までの逆算

## 1. 全体像

```
① ネタ選定 → ② データ取得 → ③ 計算・ファクトシート → ④ 台本 → ⑤ 音声 → ⑥ 映像 → ⑦ 公開 → ⑧ 振り返り
   人           自動            自動＋人が確認            LLM下書き＋人   人/TTS    Motion Engine   人         人
```

**数字はすべて③のファクトシートからしか出さない**のが、このパイプラインの背骨。
台本にも画面にも、ファクトシートにない数字は入れない。

## 2. 各工程

### ① ネタ選定
- e-Stat の「公表予定」で新しい統計が出る日を押さえる。**公表日に合わせて出すと、その週は検索が伸びる**
- 03 の企画表から選ぶ。視聴データが溜まったら、CTR・平均視聴時間の高い型に寄せる

### ② データ取得
- e-Stat API（政府統計の総合窓口）で統計表を取る。アプリケーション ID は**環境変数で渡し、ファイルや Git に書かない**
- 取得した生データはそのまま保存し、統計表 ID・取得日・URL を一緒に残す（後で出典表示に使う）
- 国税庁の民間給与実態統計調査など e-Stat に無いものは、公表ページの Excel を保存

### ③ 計算・ファクトシート
- 中央値・累積分布・差・比などをスクリプトで計算する。**ここが毎回の「自前の分析」になる**
- 出力は1本ごとに1ファイル。数字1つにつき「値・単位・出典（調査名・年・表番号）・加工手順」を持たせる
- **人が必ず目で確認する**（元の表と数字が合っているか、単位・年が合っているか）

### ④ 台本
- LLM にはファクトシートだけを渡して下書きさせる。**ファクトシートにない数字を書いたら不合格**
- 機械チェック: 台本中の数字をすべて抜き出し、ファクトシートと突き合わせる
- 人がやること: 仮説パートを書く、問いの立て方を直す、「助言」になっている文を消す

### ⑤ 音声
- **選択肢**: 自分の声で収録 / 合成音声（TTS）
- 自分の声は「人の視点がある」ことの強い証拠になり、テンプレート判定のリスクを下げる
- TTS を使う場合は、各ソフト・キャラクターの利用規約（商用可否・クレジット表記）を確認する

### ⑥ 映像（Motion Engine）
手元の Motion Engine（Storyboard → MP4、別リポジトリ）がそのまま使える部分が多い。

| 必要なもの | Motion Engine の現状 |
|---|---|
| 実データの棒グラフ＋値ラベル | **実装済み**（D-07 §7 `dataIntent → ChartProps`） |
| 出典の画面表示 | Storyboard に `citationShort`（必須項目）がある |
| 焼き込み字幕 | **既定 ON** |
| 16:9（長尺）と 9:16（ショート） | 両方対応 |
| **ナレーション音声** | **未実装**。DR-AUD-02（音声の生成主体）が未決。ここを決めないと出せない |
| 素材（線画以外） | DR-IMPL-16（調達方針）が未決。グラフ中心なら線画 58 種で当面足りる見込み |
| 分布図・折れ線・地図 | 要確認。棒グラフ以外は今後の課題 |

> **テンプレート判定への注意**: 毎回同じ背景・同じ並びのスライドだと「テンプレート的・汎用的なコンテンツ」に見える。
> グラフの種類、シーンの構成、比喩の絵を動画ごとに変えること。

### ⑦ 公開
- 概要欄: 出典の一覧（調査名・年・表番号・URL）、加工手順の要約、チャプター
- 「改変または合成されたコンテンツ」の申告: 実在の出来事と誤認されうるリアルな合成映像を使う場合に必要。
  グラフと線画だけなら通常は該当しないが、公開時に毎回確認する
- 固定コメントで「この数字、あなたの実感と合っていますか？」と問いかけ、コメントを促す

### ⑧ 振り返り
- 公開 48 時間後に、インプレッションのクリック率と平均視聴時間を記録
- 視聴維持率のグラフで、離脱が多い場所（＝どのデータブロックが退屈だったか）を見る

## 3. 公開前チェックリスト

- [ ] 画面と台本の数字が、すべてファクトシートにある
- [ ] すべての数字に出典が出ている（調査名・年）
- [ ] 加工した数字には手順が出ている
- [ ] 年収・貯蓄は中央値か分布も出している
- [ ] 仮説の部分が色で区切られている
- [ ] 投資・商品・転職先などの推薦をしていない
- [ ] 前の動画と見た目・構成が同じになっていない
- [ ] タイトル・サムネの数字が本編と一致している

## 4. 収益化までの逆算

### 期限
- いまの条件: 登録者 1,000 人 ＋ 長尺の総再生時間 4,000 時間（直近 365 日）、またはショート 1,000 万回（直近 90 日）
- **2027-02-01 以降に新規申請するチャンネルは** 8,000 時間 / ショート 2,000 万回（登録者 1,000 人は据え置き）
- すでに YPP に入っているチャンネルは影響を受けない
- → **2027-01-31 までに条件を満たして申請する**のが目標。
  （「申請日」で判定されるのか「承認日」なのかは YouTube 公式ヘルプで要確認。安全側に1月中旬を目標にする）

### 必要な再生数の目安

4,000 時間 = 24 万分。

| 平均視聴時間 | 必要な長尺の再生数 | 30 本で割ると1本あたり |
|---|---|---|
| 4 分 | 6.0 万 | 2,000 |
| 6 分 | 4.0 万 | 1,333 |
| 8 分 | 3.0 万 | 1,000 |

8,000 時間になるとこの2倍。**4か月で 30 本・平均視聴 6 分なら、1本 1,300 再生強**が目標ライン。
