# 新チャンネル企画（データ解説型）

参考チャンネル「恋愛『数字』チャンネル（Love by Numbers / [@lovebynumbers](https://www.youtube.com/@lovebynumbers)）」の作り方を分解し、
**別のテーマで同じ型のチャンネルを作れるか**を調べたフォルダ。

調査日: 2026-10-02

---

## 結論（先に）

1. **作れる。** 参考チャンネルの強みはテーマそのものより
   「**公的統計と査読論文だけで語る／出典を画面に出す／仮説と事実を分ける**」という**型**にある。
   この型は、日本の公的統計が厚いテーマならそのまま移植できる。
2. **第一候補は「お金と働き方」**（年収・貯蓄・転職・労働時間）。
   恋愛と同じく「**自分は平均より上か下か**」という比較欲求が強く、
   恋愛より広告単価がはるかに高い。助言をしない（構造だけを説明する）立ち位置にすれば、
   競合の多い「マネー系」とも、YouTube が収益化を認めない「AI の金融アドバイザー」とも重ならない。
   次点は「老後・人生後半」「子育てと教育費」。比較は [02_theme_candidates.md](02_theme_candidates.md)。
3. **期限がある。** YouTube の収益化条件は **2027-02-01 以降の新規申請から2倍**になる
   （長尺の総再生時間 4,000 → 8,000 時間／ショート 1,000万 → 2,000万回）。
   **2027年1月中に申請まで終える**つもりで逆算すると、残りは約4か月。
4. **一番のリスクは「テンプレ量産」判定。** 2025-07 に「反復的なコンテンツ」が「**不自然なコンテンツ（inauthentic content）**」に改称され、
   2026-07 に「テンプレート的・汎用的な動画」は収益化しないと明確化された。
   自動生成パイプラインを使うなら、**1本ごとに自分で計算した独自の分析**を入れることが条件になる。

## 調べられなかったこと（重要）

この環境からは **YouTube 本体・Social Blade・NoxInfluencer などにアクセスできなかった**（ネットワーク制限）。
そのため参考チャンネルの

- 動画一覧・タイトル・再生数・尺・投稿頻度
- 登録者数の推移、「2週間で収益化」の実際の数字

は**確認できていない**。分析は、検索で取れたチャンネル説明文と一般的な事実に基づく。
上記の数字を YouTube Studio の公開ページか vidIQ などから手で取って
[01_benchmark.md](01_benchmark.md) の空欄を埋めると、仮説を検証できる。
