# くわしい説明
#
# ■ 1行の書き方（どちらでも可）
#     https://item.rakuten.co.jp/shop-name/12345/   ← 商品ページのURL
#     shop-name:12345                               ← 楽天アフィリエイトの一覧から拾える形
#
# ■ 見出し（## のある行）
#   その下に書いた商品が、どのカテゴリに入るかを決めます。
#   使えるのは次のとおりです。無い見出しは自分で足して構いません。
#     food       食品・飲料・お酒
#     kaden      家電・カメラ・AV機器
#     kitchen    キッチン・日用品・DIY
#     beauty     ドラッグストア・美容
#     fashion    服・靴・バッグ・時計
#     pc         パソコン・スマホ・事務
#     sports     スポーツ・アウトドア
#     baby-toy   ベビー・おもちゃ・ホビー
#     books      本・ゲーム・エンタメ
#     pet        ペット用品
#     car        車・バイク・工具
#
# ■ 載せたものがどうなるか
#   ・トップの棚、フィード、カテゴリページの3か所に出ます
#   ・楽天の検索結果から外れても、ここに書いてあるかぎり載り続けます
#   ・売り切れ・販売終了になったときだけ、自動で落ちます
#   ・タイトルは毎日取り直します（「本日24時間限定」を残さないため）
#
# ■ 自動で外れるもの（理由は実行したときに画面に出ます）
#   ・¥5,000 を超えるもの
#   ・レビューが少ないもの、評価が低いもの
#   ・まだ販売が始まっていないもの
#
# ■ 並び順
#   トップの棚は安い順です。ここに書いた順番も、楽天の順位も使いません。
#   楽天の順位は発生報酬額の順で、高いものほど上に来るためです。
#   棚は1カテゴリ4件までですが、入りきらなかったぶんも
#   フィードとカテゴリページには載ります。
#
# ■ 値引きの表示
#   タイトルに「3,790円→1,999円」とあって、右側がいまの価格と
#   一致していれば「セール前 ¥3,790」として %OFF を出します。
#   一致しないものは読みません（別の色やサイズの値段のことがあるため）。
